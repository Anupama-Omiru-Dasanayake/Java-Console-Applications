## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/Java-Console-Applications.git
```

### 2. Open the project

Open the repository using **IntelliJ IDEA**.

### 3. Choose a project

Navigate to one of the project folders, for example:

```text
02-Calculator/src/com/anupama/calculator
```

### 4. Run the Java program

Open the Java class containing the `main()` method and run it using IntelliJ IDEA.
